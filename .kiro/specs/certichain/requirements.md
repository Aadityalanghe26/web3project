# Requirements Document

## Introduction

CertiChain is a decentralized certificate issuance and verification platform built on Ethereum-compatible blockchain networks with IPFS-backed document storage. Authorized institutions (issuers) can issue tamper-proof digital certificates that are stored on-chain and whose PDF documents are pinned to IPFS via web3.storage Storacha. Any party can publicly verify a certificate's authenticity without login. Students can view their own certificates and share verifiable links. The platform is built with React + Vite + TypeScript on the frontend, Solidity + Hardhat + ethers.js v6 on the blockchain layer, and an optional Node.js + Express + MongoDB backend for off-chain indexing.

## Glossary

- **CertiChain**: The full platform — smart contract, frontend, and optional backend combined.
- **CertiChain Contract**: The Solidity smart contract deployed on the target EVM-compatible network.
- **Certificate**: A digital record containing student information, course details, and an IPFS CID pointing to the PDF document, stored on-chain.
- **Certificate ID**: A human-readable unique identifier in the format `CERT-{YEAR}-{6-digit-counter}` (e.g., `CERT-2026-000001`), auto-generated by the CertiChain Contract.
- **IPFS CID**: A content-addressed identifier returned by the web3.storage Storacha service after uploading a PDF file.
- **Issuer**: An Ethereum account that holds `ISSUER_ROLE` in the CertiChain Contract and is authorized to issue and revoke certificates.
- **Admin Dashboard**: The authenticated frontend view available to accounts with `ISSUER_ROLE`.
- **Student Dashboard**: The authenticated frontend view available to accounts whose wallet address matches a certificate's recorded student address.
- **Public Verification Page**: An unauthenticated frontend page that accepts a Certificate ID and displays verification results from the CertiChain Contract.
- **MetaMask**: The browser wallet used for Ethereum account connection and transaction signing.
- **W3UP Client**: The `@web3-storage/w3up-client` library used to upload certificate PDF files to IPFS via web3.storage Storacha.
- **ISSUER_ROLE**: An OpenZeppelin AccessControl role granting permission to call `issueCertificate()` and `revokeCertificate()`.
- **Hardhat**: The Ethereum development framework used for compilation, local network, deployment, and testing.
- **ethers.js**: Version 6 of the ethers library used on the frontend for contract interaction.
- **Tailwind CSS**: The utility-first CSS framework used for frontend styling.
- **Lucide React**: The icon library used in the frontend UI.
- **OpenZeppelin**: The audited smart contract library providing `AccessControl` and related utilities.
